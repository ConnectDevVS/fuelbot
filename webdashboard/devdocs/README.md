# Web dashboard docs

The docs for the FuelBot web dashboard (Milestone S7). The code arrives
with the stories; until then this folder holds the plan only.

- [plans/dashboard-plan.md](plans/dashboard-plan.md): the design brief and
  page-by-page spec, decisions, wireframes, spikes, risks.
- [stories/dashboard/](stories/dashboard/README.md): the story set, SRV-27
  to SRV-49, and the SIGNOFF.
- [design/](design/):
  - the visual-direction mock-ups (`home-*.png`: desktop dark and light,
    tablet light, phone dark);
  - [claude-design-prompt.md](design/claude-design-prompt.md), a prompt
    for claude.design to design the full screen set.

The backend's source of truth is
[server/devdocs/plans/server-plan.md](../../server/devdocs/plans/server-plan.md).
